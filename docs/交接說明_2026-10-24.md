# 交接說明（2026-10-24）

> 這份文件整理了 2026-10-24 在雲端工作階段（Claude App 裡 ntu-youbike 底下的「台灣攀岩地點地圖網頁」）的過程與決定，讓之後在 climbing-map 開的新對話可以接著做。
> 資料來源的細節在 `docs/資料來源紀錄.md`，專案規則在 `CLAUDE.md`。

## 使用者的需求（原始）

1. 地圖網頁放上 GitHub，手機即時定位，自動顯示附近的攀岩地點。
2. 資料來源：Google 搜尋、Google 地圖、YouTube 搜尋「全台攀岩地點、攀岩地點介紹」，要盡量詳細、完整，並**留下操作過程和說明**，讓使用者能驗證來源可不可用。
3. 點開地點要顯示：留言、價格、圖片等。
4. 從目前位置到攀岩地點的交通建議（像 Google 地圖），重點是**大眾運輸和腳踏車**，最好能結合 YouBike 預測和站點。

## 使用者確認過的決定

| 項目 | 決定 |

| repo | 獨立成 `tim062480-create/climbing-map`（公開），不和 ntu-youbike 混在一起；Pages 已開啟 |

## 最大的問題：資料不完整（使用者發現的）

雲端環境的限制：
- 只能用內建搜尋工具（不是 Google），只看得到摘要，**打不開任何網頁**。
- Google 地圖、Facebook、Instagram 都打不開。

因此北部比較完整，**中南部、東部明顯不足**。

2026-10-24 補查花蓮，找到清單沒有的館：
- **小窩活動共享空間**（吉安，抱石＋上攀，Instagram @wooclimbing_space；營業時間平日 17:30–23:00、週六 16:00–21:00）
- **波浪岩館 Wave Rock**（抱石，預約制，全日票約 200、租鞋約 50；來源是約 2024 年初的部落格）

另外發現的錯誤：
- seed 裡的「B-Plus 抱石館（花蓮吉安）」（`bplus-hualien`）很可能是**崩NUS 教學館**（吉安，抱石 3.8m、上攀 9m）的誤植，後來改成小窩。
- 崩NUS（`bonus-hualien`）：Tripadvisor 寫週二至五 14–22、週六日 10–17、週一公休，電話 0955-475-655，網站 hualienbonus.tw，和 seed 裡的舊資料不同。
- 使用者說知道一間花蓮的攀岩場沒被收錄，**店名還沒問到**，請先問使用者。

OSM 上有、但清單沒有的候選館（見 `docs/enrich_report.md` 最後一節）：根抱石、樹抱石、瑠公攀岩基地、passion climbing 爬森攀岩館、BABO PAPAK、The Bivy、唭哩岸攀岩場、永和獅子攀岩廣場、大安運動中心、三重國民運動中心。

## 接下來要做的（建議順序）

1. 問使用者花蓮那間館的名字。
2. **逐縣市重新搜尋**，這次要點進網頁核對：
   - 地址、價格、營業時間、是否停業
   - 中南部、東部優先
   - 關鍵字中英文都要：抱石、攀岩、岩館、climbing gym、bouldering
   - 補查 Tripadvisor、theCrag、TaiwanRocks
3. 更新 `data/manual/gyms_seed.json` 和 `data/raw/sources.csv`，在 `docs/資料來源紀錄.md` 的「操作紀錄」加一段，push 之後 Actions 會自動補座標。
4. 13 間沒座標、10 間待確認的館（見 `docs/enrich_report.md`）逐一查證。
5. 之後若使用者申請 Google Places API 金鑰，金鑰存在 GitHub Secrets，由 Actions 照縣市查「抱石」「攀岩」，可以拿到地址、座標、評分、是否停業。不爬 Google 搜尋和地圖（違反使用條款）。
6. 其他待辦：
   - 開留言區（README 的步驟）
   - 手機實測網頁
   - 北部 YouBike 恢復營運後確認車數有沒有回來
