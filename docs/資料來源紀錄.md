# 抱石地圖｜資料來源紀錄

> 這份檔案記錄抱石館資料是**怎麼找來的、每一筆從哪裡來、還有哪些沒確認**，讓你可以自己照著重查、判斷來源可不可用。
> 之後每次補資料，請在「操作紀錄」加一段並註明日期。

## 1. 結論先講

| 項目 | 狀況 |
|---|---|
| 收錄 | 49 間（室內、以抱石為主；有上攀的館也收，網頁可勾「只看有抱石」）。其中 37 間營業中、10 間「待確認／可能已停業」、2 間已停業（只留紀錄，地圖不顯示） |
| 地址有門牌 | 24 間；其餘 25 間只有區域或地標（例如「內湖運動中心」），或完全找不到地址 |
| 有價格 | 27 間（不少是 2021–2024 年的文章，網頁上會標示來源日期） |
| 有 YouTube 影片 | 13 間，共 16 支 |
| 經緯度 | **還沒有**，由 GitHub Actions 在雲端用 OpenStreetMap 補上（見第 4 節），結果寫在 `docs/enrich_report.md` |

**可信度排序**（高 → 低）：館方官網／官方粉專 > 2025–2026 年的評測文章 > 沒標日期的整理文 > 2022 年以前的論壇文章或國外目錄。
每間館每個欄位用了哪個來源，寫在 `data/manual/gyms_seed.json` 的 `src` 欄位（代號對應 `data/raw/sources.csv`），網頁的「資料來源」區塊也會列出。

## 3. 怎麼驗證（建議做法）

1. **看網頁上的「資料來源」**：每間館詳細資訊最下面，每個欄位附來源連結和發布時間。
2. **重做搜尋**：第 5 節列了全部 48 次搜尋的關鍵字。用 Google 搜同樣的關鍵字，應該能看到同一批文章。
3. **和 Google 地圖對照**：打開 `docs/enrich_report.md`，每間館都有「Google 地圖」連結。對照：
   - 地址、營業時間是否一致
   - Google 地圖上是否標示「永久停業」
   - 最新評論的日期（有一年內的評論，代表應該還在營業）
4. **待確認清單**：每間館的 `verify` 欄位（網頁上是黃字「待確認」）就是我沒查到或互相矛盾的地方。優先處理：
   - 地址完全找不到：紅石新竹館、Camp4 達文西攀岩館、小岩館、Y17、iClimb 風城、B-Plus 太原館、攀吶、抱石基地、圓石空間左營店、Qingchang
   - 營業狀態不明：原岩 A19（搬遷到 A22）、原岩楊梅、POGO、二廠、舞岩、崩NUS、花蓮 B-Plus
5. **改資料**：只改 `data/manual/gyms_seed.json`。push 之後 GitHub Actions 會自動重新補座標，網頁讀的 `data/processed/gyms.json` 會跟著更新。

## 4. 自動化（GitHub Actions：`.github/workflows/update-data.yml`）

| 程式 | 什麼時候跑 | 做什麼 | 產生 |
|---|---|---|---|
| `src/enrich.py` | 每週一 02:15、`data/manual/gyms_seed.json` 或程式有改時 | 1. 用 Overpass 抓 OSM 上台灣所有攀岩地點 2. 用 `osm_keywords` 比對館名，對到就用 OSM 座標 3. 對不到就用 Nominatim 查地址（門牌 → 路段 → 地標 → 館名） 4. OSM 有但清單沒有的地點另外列出 | `data/processed/gyms.json`、`docs/enrich_report.md` |
| `src/youbike_near.py` | 每 20 分鐘 | 抓全台 YouBike 站，記錄每間館 1 公里內最近 4 站的車數，算出「平日／假日 × 每 30 分鐘」的歷史平均 | `data/processed/youbike_near.json`、`data/raw/youbike_log/日期.csv`、`data/processed/youbike_pattern.json`、`data/processed/youbike_stations.json` |

座標的可信度看 `coord_source`：`osm`（OSM 上有這間館，最準）> `nominatim:address`（門牌）> `nominatim:road`（只到路段，可能差幾百公尺）> `nominatim:place`／`nominatim:name`（地標、館名）。
`enrich_report.md` 也會列出「OSM 位置和門牌定位差幾公尺」，差很多就代表其中一個有問題。

YouBike 全台資料來源是 YouBike 官網用的 `apis.youbike.com.tw/json/station-yb2.json`，這**不是正式公開的 API**，格式可能會變，也可能擋 GitHub 的主機；擋掉時會改用臺北市政府資料開放平臺的即時資料（只有臺北市）。
